# Website Design Handoff

## References

### Site 1
**Museum of Ice Cream**
https://www.museumoficecream.com/

#### What I Like
- Consistent color palette featuring pink, red, white, burgundy, and rosy tones.
- Playful, nostalgic visual style.
- Dynamic layouts using varied grid structures.
- Large, bold, uppercase sans serif typography for headings.
- Consistent font usage throughout the site.
- Text color changes on hover.
- Navigation reveals additional information inside rounded oval-shaped dropdowns.
- Animated hero videos and interactive visual storytelling.

### Site 2
**BonBon NYC**
https://bonbonnyc.com/

#### What I Like
- Baby pink and navy color palette.
- Combination of serif and sans serif typography.
- Interactive hover effects including underlines, image movement, and background color transitions.
- Consistent branded graphics.
- Flexible grid layouts with a foundation of four-column sections.
- Playful and memorable user experience.

---

# Creative Direction

## Overall Mood
Playful, nostalgic, energetic, candy-inspired, bold, interactive, and imaginative.

The final experience should feel like a blend of Museum of Ice Cream and BonBon NYC while serving as a colorful and engaging portfolio experience.

# Color Palette

## Primary Background
`#ff1a75`

Bright candy pink.

## Primary Text
`#ffffff`

Clean, high-contrast white.

## Accent Color
`#cce6ff`

Used for:
- Links
- Borders
- Buttons
- Underlines
- Interactive highlights

### Color Ratio
- 60% Pink (`#ff1a75`)
- 25% White (`#ffffff`)
- 15% Accent Blue (`#cce6ff`)

---

# Layout

## Desktop Grid
- 12 columns

## Mobile Grid
- 2 columns

## Hero Section
- Hero image spans 8 columns
- Name/title spans 8 columns

## Layout Approach
Use a combination of:
- Full-width sections
- Asymmetrical grids
- Alternating content layouts
- Overlapping visual elements
- Dynamic spacing and composition

The page should avoid feeling rigid and instead feel expressive and playful.

# Interactive Effects

## Text Hover
- Color transitions
- Animated underline effects

## Image Hover
- Gentle wiggle or shake effect
- Slight scaling
- Playful motion

## Decorative Graphics
- Floating branded graphics
- Consistent visual language throughout the site

---

# Moving Background

## Mouse Spotlight Effect

### Behavior
- A circular spotlight follows the cursor.
- Background colors react underneath the cursor position.
- Creates an interactive light-reveal effect.
- Works across major sections of the page.

### Speed
- Medium

### Motion Style
- Smooth easing
- Soft glow
- Fluid transitions
